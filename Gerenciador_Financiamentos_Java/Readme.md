# Gerenciador de Financiamentos

## Sobre o projeto

Este projeto é um **gerenciador de financiamentos** desenvolvido em **Java** como atividade da disciplina de **Fundamentos de Orientação a Objetos**.

A aplicação funciona exclusivamente por **linha de comando**, sem interface gráfica, e tem como principais objetivos praticar **Programação Orientada a Objetos (POO)**, desenvolvimento em Java e aplicação de regras de negócio.

## Objetivos

Os principais objetivos do projeto são:

- Praticar conceitos de **Programação Orientada a Objetos**;
- Desenvolver e aprimorar conhecimentos de **Java**;
- Aplicar **regras de negócio** em uma aplicação prática;
- Exercitar a organização de um projeto utilizando diferentes classes;
- Desenvolver uma aplicação funcional utilizando entrada e saída pela linha de comando.

## Funcionamento

O sistema é executado pelo terminal e toda a interação com o usuário acontece por meio da **linha de comando**.

Não há interface gráfica. As informações são apresentadas no terminal e as entradas são fornecidas pelo usuário durante a execução do programa.

## Organização do projeto

O código é organizado em arquivos separados por responsabilidade, utilizando a divisão entre **main**, **modelo** e **util**.

### Main

Contém a parte responsável pela execução do programa e pelo fluxo principal da aplicação.

É a partir dessa estrutura que o sistema é iniciado e as operações são conduzidas.

### Modelo

Reúne as classes que representam os elementos utilizados pelo sistema.

Essa divisão permite organizar os dados e comportamentos relacionados aos objetos do projeto, seguindo a proposta da Programação Orientada a Objetos.

### Util

Contém classes e recursos auxiliares utilizados pelo sistema.

A separação dessas funcionalidades contribui para manter o código organizado e distribuir melhor as responsabilidades.

## Programação Orientada a Objetos

Por ser um projeto desenvolvido para a disciplina de **Fundamentos de Orientação a Objetos**, a aplicação busca colocar em prática conceitos fundamentais de POO.

A utilização de diferentes classes permite representar partes do sistema de forma separada, contribuindo para uma melhor organização do código e para a aplicação das regras de negócio.

## Regras de negócio

O projeto também tem como objetivo trabalhar com **regras de negócio** relacionadas ao gerenciamento de financiamentos.

Essas regras fazem parte da lógica da aplicação e definem as condições que devem ser consideradas durante as operações realizadas pelo sistema.

## Tecnologias utilizadas

- **Java**
- Aplicação executada por **linha de comando**
- **Programação Orientada a Objetos**



## Conclusão

O Gerenciador de Financiamentos é uma aplicação desenvolvida em Java com foco no aprendizado de **Programação Orientada a Objetos**, na organização do código em diferentes classes e na aplicação de **regras de negócio**.

Por funcionar via linha de comando, o projeto concentra seus esforços na lógica da aplicação, na estrutura das classes e na implementação dos comportamentos relacionados ao gerenciamento de financiamentos.
