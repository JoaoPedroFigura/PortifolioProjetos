# Trailer feito para servidor de Minecraft

## Sobre o projeto

Este projeto consiste em um **trailer feito para um servidor de Minecraft**, produzido por mim, desde a gravação até a edição final do vídeo.

O objetivo do trailer foi apresentar a nova temporada do servidor visando mostrar as funcionalidades do servidor e atrair novos jogadores.

## Ferramentas utilizadas

Para a produção do vídeo, utilizei apenas ferramentas gratuitas:

- **OBS Studio** — utilizado para realizar as gravações.
- **CapCut** — utilizado para a edição, cortes, efeitos e finalização do vídeo.

## Autoria

Todo o processo de criação foi realizado por mim, incluindo:

- Planejamento do vídeo;
- Gravação das cenas;
- Aplicação de efeitos e transições;


Este projeto demonstra minha experiência com **gravação e edição de vídeo**, utilizando ferramentas gratuitas.

**Partes do texto tiveram intervençao de I.A para proporcionar um melhor entendimento.**
