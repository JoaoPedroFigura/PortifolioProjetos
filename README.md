# Portifolio de Projetos para o programa Apple Developer Academy PUCPR

Este repositório reúne projetos desenvolvidos por mim, sendo dois deles trabalhos da faculdade e o outro um trailer para um servidor de Minecraft.

## Projetos

### 1. Gerenciador de Financiamentos — Java

Sistema desenvolvido em **Java** com o objetivo de praticar conceitos de **Programação Orientada a Objetos (POO)** e implementação de **regras de negócio**.

### 2. Gerenciador de Séries Favoritas — Python

Sistema desenvolvido em **Python** para praticar **lógica de programação** e operações **CRUD** (Create, Read, Update e Delete) através do gerenciamento de uma lista de séries favoritas.

### 3. Trailer para Servidor de Minecraft — CapCut e OBS Studio

Trailer desenvolvido com o objetivo de realizar a **divulgação de um servidor de Minecraft**, explorando a criação de conteúdo audiovisual voltado à apresentação e promoção do servidor.
