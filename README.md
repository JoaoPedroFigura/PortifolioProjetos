# Portifolio de Projetos para o programa Apple Developer Academy PUCPR

Este repositório reúne projetos e experiencias de T.I que tive ao longo de minha vida!
## Projetos

### 1. Gerenciador de Financiamentos — Java

Sistema desenvolvido em **Java** com o objetivo de praticar conceitos de **Programação Orientada a Objetos (POO)** e implementação de **regras de negócio**.

### 2. Gerenciador de Séries Favoritas — Python

Sistema desenvolvido em **Python** para praticar **lógica de programação** e operações **CRUD** (Create, Read, Update e Delete) através do gerenciamento de uma lista de séries favoritas.

### 3. Trailer para Servidor de Minecraft — CapCut e OBS Studio

Trailer desenvolvido com o objetivo de realizar a **divulgação de um servidor de Minecraft**, explorando a criação de conteúdo audiovisual voltado à apresentação e promoção do servidor.

# Experiências 

### Mini Empresa JK3D:

Foi um projeto na escola que simulava o funcionamento de uma empresa, obtive muitos conhecimentos sobre o dia a dia Empreendedor.

### Maratonha Tech:

É uma competição de tecnologia entre as escolas do Brasil com o foco em aprendizado sobre Pensamento Computacional e Lógica de programação.

### Programa Aluno Monitor:

Foi um periodo em que frequentava a escola fora do meu turno de aula para ajudar os alunos de outras turmas com dificuldades nas disciplinas envolvidas com informática,
além disso também auxiliava a escola a manter o hardware funcionando, como solucionar problemas simples de software ou corrigir desconexão nos cabos dos computadores.
